## 🚀 如何預覽與啟動

### 方式 1：直接開啟
直接在瀏覽器中雙擊或開啟 `index.html` 即可完整瀏覽與體驗所有互動功能。

### 方式 2：使用本機伺服器
```bash
# macOS 內建簡易伺服器
python3 -m http.server 8000
# 或使用任何靜態伺服器 (如 serve, npx http-server)
```
瀏覽器開啟：`http://localhost:8000`
